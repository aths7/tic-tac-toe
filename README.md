# Tic Tac Toe 🎯

- [Play](https://stupendous-choux-df0c4d.netlify.app/)

A modern, interactive Tic Tac Toe game built with **Next.js**, **Tailwind CSS**, **Framer Motion**, and custom sounds.

## 🔥 Features

- 3D-styled buttons with click sounds 🔊
- Auto-remove oldest move after 3 turns per player
- Win detection with confetti 🎉 and win sound
- Responsive UI built using Tailwind CSS
- Deployable as a static site on Netlify

## 🧱 Tech Stack

- [Next.js 15](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Netlify](https://www.netlify.com/)
- Custom audio from `/public/handgun.mp3` and `/public/win.mp3`
